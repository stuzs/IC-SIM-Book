集成电路仿真十讲 - Ten Tutorials on IC Simulation

第一章 硅晶圆上的芯片排布

1.1 程序主体

程序脚本文件名称：iccad_mpw.py

程序说明：光刻是集成电路制造过程所围绕的中心加工步骤。光刻工艺要求事先制备一套多达几十张的光掩模；在具体光刻操作时光刻机的每一次曝光可以将一张光掩模上的图形模式转移到硅晶圆表面。
本程序是多项目晶圆(MPW, Multi-Project Wafer) 所使用的光掩模上的芯片排布和光刻机顺序步进曝光的一个简化示例。程序仿真了各MPW芯片在硅晶圆上多个位置的光刻投影，并且演示了Python的基本语言元素以及如何在Python中建立图形用户界面(GUI, Graphic User Interface)。

图1-1 show_mpw( ) 运行结果

show_mpw( )的结果显示了在一张光掩模上多个项目的芯片的位置安排。集成电路设计企业在集成电路试制阶段有可能参加此类MPW计划，也就是让试制芯片“搭乘“硅晶圆代工制造厂定期安排的、多家设计企业可以共同乘坐的“流片班车“(shuttle bus, 穿梭班车)，以节约光掩模制造的费用。如图中可能有7家企业的试制芯片共同分享同一张光掩模；一套光掩模中其它几十张也按照此图中同样的几何位置分配给各家的芯片项目。

在MPW试制完毕拿到芯片样品后，如经周密测试一切顺利，产品进入大规模量产时，本次MPW的光掩模还有用吗？答案是这次的光掩模上还有其它企业的不少芯片版图，这套光掩模本身一般就不用了，但试制成功的本企业芯片的设计版图还是有用的，可以把要投产的芯片版图原样重复排列例如9次(3行 x 3列)或20次(4行 x 5列)等等，制造成一套新的光掩模，用于实际量产。

图1-2 不同输入变量的fields( )运行结果

fields( )的结果显示光掩模经光刻机投影到硅晶圆上以后，硅片上的投影区域也即“曝光场“(exposure field，而曝光动作名词常称为exposure shot或简称shot)的位置；在赋值给参数detail=True后，还可以看到各个多项目芯片的详细投影位置。

fields( )函数的参数中除了detail以外，还有diameter用来定义硅晶圆的直径。硅晶圆直径常见的为12英寸，也即300mm晶圆，一般使用铜互连工艺的硅晶圆都是12英寸。历史上半导体晶圆有8英寸(200mm)、6英寸、4英寸等直径值，随着一代一代集成电路工艺的发展，晶圆直径变大，这样一片晶圆上可以产出更多的芯片，其产出数目在晶圆上芯片的详细位置图中有直观体现。目前在成熟特色工艺（如模拟、高压、传感器、化合物等）制造中，8英寸及更小直径晶圆也是常见的，同学可以输入对应fields( )参数diameter的直径值进行仿真观察。如果同时输入diameter=450及detail=True，可以看到预想中18英寸晶圆的芯片产出情况；18英寸晶圆设备的开发应用在2015年前后已被国际巨头们宣告放弃，主要还是由于设备依赖链太长削弱了投入/产出效益。

fields( )函数的前两个参数width和height，用来定义光掩模的尺寸。实际光掩模的尺寸比它在硅晶圆表面的投影尺寸要大好几倍，典型的投影缩小比例为1:4；光掩模的实际尺寸较大，上面的微细图形用电子束直写加工的难度也就降低。由于不同光刻机的投影缩小比例未必相同，甚至在极紫外(EUV, Extreme Ultra Violet)光刻的镜面反射投影系统中，光掩模的水平/垂直方向的投影缩小比例也不一致，因此这里fields( )统一使用投影到晶圆上的光掩模投影尺寸作为width和height的取值，而不考虑光掩模实际的物理尺寸；如fields(30, 20)即表示光掩模在硅晶圆上的曝光场大小为30mm x 20mm，即晶圆上600mm²的曝光面积。光刻机有曝光场尺寸的上限，光掩模的水平/垂直尺寸在该上限之内稍调整得小一些是允许的，但如光掩模尺寸变小的话，每片晶圆的曝光次数就要增多，这将占用更多的光刻机机时；当然另一方面，光掩模小一些的好处是制作光掩模的费用可以节省，该费用是一笔巨大的一次性投入，其价格和掩模面积成正比。实际曝光次数在fields( )函数运行时由print( )报告输出。

1.2 问题需求和算法背景

经过程序运行并观察输出结果后，可以对程序要解决的问题做一归纳：
已知有一批MPW项目芯片的版图，已确定其大小和在光掩模上的排布位置（坐标等几何数值均已按1:1投影比例调整），存在一个列表(list)中。需要：

  1. 显示图形，描绘光掩模上各芯片版图排布情况。
  2. 显示该光掩模经过光刻机按各场区域为顺序曝光后的硅晶圆图形。

在Python环境中需要创建较为简单的GUI，优先选择Tkinter库，其特点是简单易用。Tkinter作为Python的标准GUI开发工具已近30年了。当年John Ousterhout教授以开源形式发布的Tcl脚本语言(Tcl or TCL，全名Tool Command Language)就是为了解决ICCAD流程中各个EDA点工具内部的语言系统过弱的问题；这里的tool当初就是指的IC design tool。把开源、可扩展的Tcl语言解释器嵌入到各EDA工具中，各工具可以借用该语言核心并定制添加自己的Tcl命令，然后在ICCAD流程中就可以用Tcl脚本把一批EDA工具链接起来。之后在Tcl语言上又扩展出了Tk工具箱，也就是在Tcl语言的命令行界面(CLI, Command Line Interface)新增了一批专门用于GUI操作的定制命令。Tcl语言发展至今，在ICCAD软件工具中的应用相当普遍，比如广泛用于交互界面、文件输入输出、自动流程控制、计算和分析脚本，以及对如时序约束的描述等。近年来在主流ICCAD工具所采用的用户端语言中，Python的使用也在逐步推开，但Tcl的主力地位仍然难以替代，同学后续如遇到Tcl语言环境也须能较快学习上手。

本程序中导入使用的Tkinter库也就是Tk interface的意思；这个库为Python提供了Tk专门命令的一个使用接口，使我们在Python中可调用这个接口上的函数去实际使用Tk。在本程序内还给了Tkinter库一个快捷的短别名，就叫tk。代码见下：

    10	import tkinter as tk

本程序内用到的Python基本数据类型有：

  • 元组(tuple) – 程序中用到了一个tuple存放顺序排列的4个数，表示一种芯片的具体位置和大小。元组以一对圆括号 ( ) 作为标记。元组创建赋值以后其具体值就不能动了。
  • 列表(list) – 程序中用到了list来顺序存放各个芯片的位置和大小，即该列表的每个元素是一个上述的tuple。列表以一对方括号 [ ] 作为标记。列表的元素是可以添加、修改、删除的。

对于Python的基本语素、语法，如果此时同学了解尚不够全面，也没有什么问题，多看多试多问，应可相当快地入门掌握。比如list, tuple类型在本程序中出现，可以观察其如何赋值，如何操作等，后续即可主动用于自己的编程练习中。为了将内容聚焦到集成电路仿真本身，代码讲解时会简化Python程序中一些风格细节、替代可能等叙述，留给同学后续自己来慢慢细化吸收。

1.3 代码讲解

本程序中有2个主要的命令函数，show_mpw( )和fields( )。可以从show_mpw( )这个相当简单的图形命令函数开始讲解。

首先看到的show_mpw( )的函数定义行，以def 开头，以 “:”（可以称冒号为colon）结束。show_mpw( )函数仅能接受一个参数n定义画布的放大倍数；如果不输入任何参数，n的缺省值就为10。下面以3个双引号开始和结束的文档字符串(docstring)说明本函数的功能和用法等，在Python交互时如执行help(show_mpw)可随时显示。函数如将作为API接口对外开放，全面说明是必备的。

创建一个空的列表变量singleMPW，等号右侧的[ ]符号即规定了singleMPW这个变量的类型为list，目前暂时为空。下一步，将singleMPW变量作为输入变量，调用另一函数mpw( )。mpw( )的代码稍后讲解。这次执行的结果是singleMPW从mpw( )带回了 MPW光掩模上各个芯片的位置和大小，即singleMPW的每一个元素代表一种芯片，均为由4个数值并列构成的tuple；同时mpw( )函数本身返回了一个由2个数值构成的tuple，表示正好包围所有芯片的边界方盒的宽度、高度，这也就是为了本次MPW要制造的光掩模的大小（尺寸按1:1投影的理想假设）；代码中，返回的tuple中的宽高尺寸数据分别赋值给了数值变量w和h。

有了各个芯片的位置和大小，以及包含所有芯片的光掩模宽高后，即可使用Tkinter绘制图形。其主要步骤为：

  1. 调用tk.Tk( )，返回变量root。tk.Tk( )返回的是新建GUI窗口的“根“。另可以在交互环境中试着创建一个新的变量也等于tk.Tk( )，应能看到出现新的空白窗口。
  2. 在root上创建一个Tk中规定的绘图画布Canvas，变量的名字叫cv，根据所有芯片的边界方盒大小决定画布的高度、宽度，并且计划在四周留一点窄边；定义实际的画布大小时，缩放因子n产生作用。
  3. 将画布cv安放进上级窗口，不用指定太具体的坐标位置，即调用cv.pack( )。
  4. 在画布上先绘制一个浅灰色的矩形，作为绘制芯片的底色区域，画布周围留出10个像素点的窄边。
  5. 从列表singleMPW中一个一个把代表各个芯片位置和大小的tuple用for循环拿出来，tuple中的4个数值分配给4个变量x, y, w, h，将这些芯片逐个在画布上绘出位置轮廓，轮廓的宽度为3个像素，内部填充普通灰色，n为图形放大因子。这里的变量w, h和前几行代码中的w, h重名了，是否可以？答案是虽然易混淆，但语法上没问题，变量可以重复赋值，后值会覆盖前值。
  6. root.mainloop( ) 进入图形界面的循环中，直到同学关闭这个MPW光掩模的显示窗口。

下面简单看一看函数mpw( )。其参数仅一个，为上级程序调用函数时传送来的列表型变量dlist。文档字符串描述了函数目的：将待求的光掩模曝光场的宽度、高度从一个元组wrap中返回；而且将所有芯片（硅晶圆上的单独芯片可以称为die，其复数为dice）的左上角坐标、宽度、高度（也即x/y/w/h）存放到输入列表dlist中。所有芯片的位置和大小信息原先已经存在一个列表变量planned中，该变量中的芯片位置、宽高信息可能由一个自动的MPW布局优化器生成，但这里为了演示目的直接给出了一个确定了的布局计划，跳过了自动优化步骤。元组wrap的内容为正好包围所有芯片的边界方盒尺寸。

在给定MPW中所有芯片矩形的位置、宽高以后，边界方盒的尺寸应该是唯一确定的，同学在本章作业中可以试着从列表变量planned中读取所有芯片的信息，计算求得边界方盒尺寸。在本函数原始代码中，直接给出了对应的边界方盒尺寸wrap为(30, 20)。

下一步从列表变量planned中循环将所有芯片的位置、宽高信息拷贝到输入列表变量dlist中。代码中使用了列表的元素添加功能append( )，将每个芯片的信息一次一个添加到dlist本身的数据链中。注释行中也询问同学，直接用等号实现两个列表的赋值行不行？可以试着直接赋值，并且在mpw( )函数内打印被赋值的列表变量；然后对于列表用append( )添加元素和直接用等号赋值这两种情况，在show_mpw( )中调用mpw( )以后，都打印singleMPW的值来看一看，是否被赋上了mpw( )中planned的值。这些操作便于同学直接体验到在Python中同一内存地址的变量别名、函数作用域等常见疑难。在Python中列表、字典、集合等一类可变（即Mutable）变量的赋值类型有别名引用（即仅传递内存地址）、浅拷贝(shallow copy)、深拷贝(deepcopy)；本书点到即止，不展开详细讨论；其原理上与C语言中变量的内存安排和管理模式是相通的。在C语言中函数内部的变量如果是static型，其地址仍然可以通过指针变量传送出去到整个程序实现有效访问，但Python中没有直接的对应机制，需要费一些心思来考虑把变量“粘贴“到一个主程序运行起来会留出静态位置的内存地点，但一般情况也不刻意强求。

接下来看用于硅晶圆上曝光场显示的命令函数fields( )。fields( )函数有4个参数，其中参数width和height用来定义每一次曝光的光场宽、高，缺省尺寸为30mm x 30mm，这同时也就是按照1:1投影理想假设下的光掩模大小。参数diameter定义晶圆的直径，缺省是300mm(12英寸)。参数detail是一个布尔值（仅取值True或False），用来决定是否绘制曝光场内各个芯片的详细位置形状；如果detail的值为True的话，参数width, height就不起作用，此时所有各个芯片的位置形状、外围边界方盒的尺寸会通过详细查问mpw( )直接获得。fields( )函数的代码结构并不复杂，仅有两个逻辑分支都是为了处理当detail为真时的额外任务。整个晶圆的圆心可能正好和圆心附近几个相邻曝光场的矩形四角顶点重合，或圆心正好在某曝光场的矩形中心，或有其它可能；本程序中仅使用晶圆圆心正好和曝光场四角重合作为示例。

    60	def fields(width=30, height=30, diameter=300, detail=False):
    61	    """Expose many fields (shots) on wafer by a stepper; each field has its
    62	    width and height; each wafer has a specified diameter, the default
    63	    'diameter=300' indicating a 12 inches wafer.
    64	    When setting argument 'detail=True':
    65	        Parameters 'width' and 'height' then have no meaning at all;
    66	        mpw() will return a list of die positions and dimensions, and
    67	        then each die inside each field is drawn finely.
    68	    The wafer center might be on a field center or on field corners,
    69	    but here to demonstrate Python list, we only implement the latter.
    70	    """

fields( )和show_mpw( )一样使用Tk图形界面，图形绘制在画布cv上，画布大小为3倍晶圆半径 x 2.5倍晶圆半径（即1.5倍晶圆直径 x 1.25倍晶圆直径），这样在晶圆图左右留有一些空白。以画布中心作为晶圆圆心，绘制红色的晶圆边缘；再将画布在窗口中安排合适位置，也即调用函数cv.pack( )。

fields( )函数然后判断参数detail的值如为True的话，从mpw( )返回的tuple中获得光掩模宽高，而将列表变量dice_list传递进mpw( )，带回来所有MPW芯片的位置、大小。接下来以晶圆圆心作为坐标系原点(0, 0)，生成包含所有曝光场左下角X/Y二维坐标的一个列表xy_list，光刻机可以根据这个列表来移动晶圆相对于曝光镜头的位置，实现一步一步的“步进式“曝光。在代码中，生成xy_list分为两个步骤，首先生成第一象限X方向上和Y方向上可能安放曝光场左下角的离散格点坐标，形成两个列表x_list和y_list；其次，利用这两个列表，在四个象限上均生成曝光场左下角二维坐标的列表，并将4个列表拼装成xy_list。下面选两段代码作为例子来看一看Python中从循环变量生成列表的一种简洁方法，列表推导式(List Comprehension)，其基本创建语法仅一句为：

[expression for element in iterable if condition]

代码段1：

x_list = [x for x in range(0, radius, width)]

右侧生成的列表中的元素的表达式是x，直接等于后续的element x，它是从range( )所生成的一个等差数字序列中一一提取元素得到的，而这个等差序列是从原点的X轴坐标0到X轴最大可能取值坐标（最大不会大于半径）之间每隔一个曝光场宽度取一点构成的。同学可以感觉到列表推导式语法是汉语中的倒装句式否？先说重要的，新列表的元素怎么从原来的元素构造，再说补充的，原来的元素从哪里来。

代码段2：

[(x, -y - height) for x in x_list for y in y_list]

该推导式生成的列表，其元素表达式是(x, -y-height)，即每个元素是由两个数值排列成的一个元组。表达式中的x, y是在后续for中提及的推导变量element，分别从x_list和y_list两个列表中的元素一一取得其值。height不在推导式的变量中，因此作为一般变量参与运算即可。整句代码是生成第四象限内曝光场左下角二维坐标的列表，其中每一点的X坐标和第一象限点坐标相同，但Y坐标和第一象限点坐标符号相反并相差一个曝光场的高度值。

加号是有效的列表运算符。四个象限中曝光场左下角二维坐标的列表可以用加号加起来，形成一个包含它们的大列表xy_list。如果Python代码行太长，可以分写成几行，但需注意用反斜杠符号结尾，“\“指示下一行还是本行的继续（可以称反斜杠符号为back-slash）。本程序内其实也还有其它的续行写法，可以自行寻找一下。有了xy_list以后，光刻机其实就可以动作起来进行步进式曝光了。在本函数中则增加了一个检查，判断本次曝光场在给定左下角坐标和宽、高以后，是否完全在晶圆以外？即只要曝光场和晶圆沾上一点边，就执行曝光；或同义表达为，如果xy_list中有的曝光场是在晶圆边缘以外的，比如整个光场偏在晶圆某个象限的圆弧以外，那不需要曝光。如果曝光场和晶圆确实是有沾边的，就画出此次的曝光场矩形轮廓；如果同时输入变量detail也为真，那么把这次曝光场内的所有MPW芯片的位置大小也详细绘制出来，其相关信息前面已经由调用mpw( )保存到dice_list中了。

程序中另有一个函数fully_outside( )，其目的如函数名所示，是为了判断曝光场是否完全在晶圆之外（即完全不沾边）。代码判断曝光场4个顶点的坐标是否在晶圆外，如果某顶点在晶圆外，则该顶点到晶圆圆心的距离的平方大于晶圆半径的平方；如果矩形4个顶点都在晶圆以外，则判定曝光场在晶圆以外。代码以逻辑运算符“and“实现了4个条件的“与“。这样判定看实验结果基本上是可行的，但几何上并不严格，后续可以再向前讨论一步。

本章相关的辅助程序为：ds_mpw_pack.py。该程序用来帮助解答同学会提出的一个疑问：对于本章中的7个MPW芯片，是否存在更小于575平方毫米的边界方盒？也即对于一批矩形MPW芯片，允许各自旋转90度但不可以相互重叠，求包含它们的最小面积的边界方盒。

本问题是经典的“二维矩形装箱问题“中的一种最小化满装容器成本的实例。该问题是NP-困难问题（其中NP, Nondeterministic Polynominal指非确定性多项式时间复杂度），其最优解一般没有办法在多项式时间内获得，而仅能通过“启发式方法“也就是说因题制宜，找到实验表现较佳的近似较优算法来求解。人类对装箱(Bin Packing)类问题及其各种约束条件变化后派生问题的研究已有相当的积累，相关知识和算法文献较丰富，因此也被人工智能LLM所充分吸收。对于本问题中矩形数目不多的情况，作者用适当的提示词要求LLM生成了ds_mpw_pack.py程序，运行该程序可以搜索获得面积较小的边界方盒，但未必能保证是最优解。从EDA的四个台阶层次来说，这已经从simulation台阶跨到了optimization台阶。

该程序假设矩形都是“砖块“，尝试使用不同的宽度W作为“砌墙“的地基宽度（在图1-4中是向下方进行“砌墙“）；固定W时尝试所有可能的砖块排序、也包括是否旋转砖块的组合，按所有组合顺序一一取出砖块从左到右摆放砌墙；找到取各个W值时高度H最低的墙，计算W*H面积比较取优即可。在顺序摆放砖块时使用了一种尽量降低当前墙高的“贪婪“算法(Greedy Algorithm)，部分简化了二维摆放自由度过大的问题；此算法在取砖砌墙时保持追踪当前墙最高处的“天际轮廓线“以决定向何处垒放新加的砖块，故常称为“天际线“(Skyline)算法。

图1-4 面积更小的MPW布局

运行ds_mpw_pack.py，其最外层循环穷举所有可能的宽度W值，在循环内使用“天际线“算法将各种可能组合的砖块序列全部尝试砌一遍（函数名为pack_sequence），整个过程还是需要花费较长时间的，同学应保持足够耐心。如果算法在砌墙过程中足够聪明，能不断审视已尝试其它W值获得的当前最优解，本次砌墙砌到一定高度后可能就判断不必再砌下去了（即半途而废某些尝试途径，或称分支限界树状搜索的“剪枝“），这样可节省计算时间。图1-4的结果显示该种布局的方盒面积为15 x 37 = 555平方毫米。如果实际使用光刻机在晶圆上的曝光场尺寸上限低于37mm，可以在ds_mpw_pack.py中添加该尺寸的上限约束，这样所探索的W取值和H取值的范围变小后，求解过程也可能成倍加速。
