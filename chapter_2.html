第二章 求解线性电路

2.1 程序主体

程序脚本文件名称：iccad_mna.py

程序说明：本程序是一个对线性电路实现直流分析的仿真器。线性电路直流分析所采用的基本算法为节点法(NA, Nodal Analysis)和改进节点法(MNA, Modified Nodal Analysis)；主要计算任务为求解多元线性方程。电路描述文件参照SPICE格式；矩阵计算则全力依靠NumPy计算库。
程序演示了NumPy中常见的基本操作，也演示了Python中的进一步数据结构类型如类、集合、字典，以及基本的文件I/O、出错处理机制等。

主体代码流程框图为：

flowchart TD
    A([START]) --> B[Step 1. Get netlist file name]
    B --> C[Step 2. Parse netlist line-by-line into a list of Components]
    C --> D[Step 3. Whether V-source exists decides using NA or MNA]
    D --> E[Step 4. Assemble matrices<br/>G, B, C, D, Isrc, Vsrc]
    E --> F[Step 5. Solve linear system for NA or MNA]
    F --> G[Step 6. Print node voltages, and V-source currents if MNA]
    G --> H([END])

2.2 问题需求和算法背景

经过程序运行并观察输入电路描述文件、输出结果后，可以对程序要解决的问题做一归纳：
已知线性电路包含最基本的线性电阻（欧姆电阻）、直流电流源、直流电压源；该电路的元件名、元件参数、元件之间的连接关系均由一个电路描述文件确定，该文件参考使用SPICE格式。需要：

  1. 求解电路各个节点的直流电压值，并输出。
  2. 如果电路包含直流电压源，求解流过该电压源的直流电流值，并输出。

要解决以上问题，其基础知识在大学程度《电路原理》或类似课程中应已覆盖。人类在200多年前发明了电池，在当时的环境条件下要经过四五十年时间研究，才逐步掌握直流网络中电流、电压的基本关系，由基尔霍夫总结成了KCL(Kirchhoff’s Current Law), KVL(Kirchhoff’s Voltage Law)这两条关于电流、电压的物理量守恒定律；发明研究过程中应该提到的科学家名字还有伏特、欧姆（他们的名字也成为程序中反复使用的计量单位；另一位科学家安培则主要研究磁场和电流的关系）。本书不重复讲述这些基础知识，而是从实际电路例题的方程建立起步，从两个简单特例推广到一般线性电路的求解。

图2-2 电路mna_exm1的原理图和网表

例题mna_exm1(“mna_exm1.spice“为文件全名)的电路描述文件参照SPICE电路描述格式，因该文件描述了电路的网络连接关系，也可称之为SPICE网表(net-list或netlist)。从电路原理图创建SPICE网表时，先要为电路图中每个节点选定不重复的节点名，其中“地“节点名称必为“0“或“GND”。然后对于电阻，以每一行文字描述一个电阻，以空格分成4个字段（由空格分隔的字段也叫field）。第一字段为电阻名称，以字母“r“或“R“开始；第二、第三字段为电阻连接的两个节点名称；第四字段为电阻的阻值。由于SPICE格式不区分字母大小写，因此下面再同时提及文件某位置上的大写、小写字母时，仅提及其中之一。对于直流电压源，第一字段为电压源名称，以字母“V“开始；第二、第三字段为电压源连接的两个节点名称（有正负极性连接的区别）；第四字段为电压值。对于直流电流源，第一字段为电流源名称，以字母“I“开始；第二、第三字段为电流源连接的两个节点名称（有电流流向的区别）；第四字段为电流值。

将本程序中用到的简化SPICE电路描述格式总结如下：

星号("*")起始的行，是注释行
电阻名(R起始)		节点名1		节点名2		电阻数值
电压源名(V起始)		正极节点名	负极节点名	电压数值
电流源名(I起始)		流出节点名	流入节点名	电流数值

例题mna_exm1的电路，除了地节点0以外，其它共3个节点，名称分别为“1“, “2”, “3”。 节点法NA，又称节点电压法，即以各个节点的电压作为未知量（此处即三个节点的电压值v1, v2, v3）；根据KCL，每个节点流入、流出的电流值之和应为0，因此可依据KCL为3个节点各建立一个方程。流过电阻的电流可以依据欧姆定律，由电阻两端的节点电压之差除以电阻值唯一确定。3个节点的方程构成了三元一次方程组如下：

rg​v1​−0​+rx​v1​−v2​​+rz​v1​−v3​​rx​v2​−v1​​+∞v2​−0​+ry​v2​−v3​​rz​v3​−v1​​+ry​v3​−v2​​+∞v3​−0​​=ix​=0=iz​​(Equ. 2-1)

方程组中第2行第2列、第3行第3列处均留空。这两处可填写从节点接地电阻上流出该节点的电流。本电路中不存在这两处接地电阻，即两节点直接接地电阻值均为∞，也即对地电导值均为0，因此留空。

对于 A∗x=b 型的多元线性方程组的求解，从中学代数课开始学习研究，在大学程度《线性代数》或类似课程中已深入覆盖。在本程序中，借助NumPy库，使用常规的矩阵方法来求解线性方程组。对方程组(2-1)代入具体电阻、电流值后，整理得到：

4∗v1​+(−1)∗v2​+(−2)∗v3​(−1)∗v1​+2∗v2​+(−1)∗v3​(−2)∗v1​+(−1)∗v2​+3∗v3​​=1=0=1​(Equ. 2-2)

表达为矩阵形式为：

​4−1−2​−12−1​−2−13​​​v1​v2​v3​​​=​101​​

对于一般形式的线性方程组 A∗x=b，使用矩阵求逆计算得到非奇异矩阵A的逆矩阵inv(A)后（也即 A−1），可解得 x=inv(A)∗b。对应方程组(2-1)，可解得v1=2V, v2=2.2V, v3=2.4V。同学可以将此解代入方程组(2-1)验算一次，并在图2-2电路原理图上标注出三处节点电压值。

普遍情况下，电路支路数目大于节点数目（mna_exm1含地共4个节点、6条元件支路，独立回路数为3、简单回路数为6）；节点数为n，如各节点之间均有连接，支路数即多达n*(n-1)/2。如使用电路支路构成回路，对每个回路适用KVL建立方程，则所列方程数目会更多；采用节点电压作为未知量适用KCL，方程的数目可以减小，更适合矩阵求解时提高计算效率。目前ICCAD流程中使用的主要电路仿真器均采用基于节点的直流工作点分析法。

但对于含有独立电压源、受控电压源的电路，基于节点的方法在求解时尚需特殊考虑。仅以增加一个独立直流电压源V_add为例，如：

  1. 电压源V_add加在某节点和地之间，则该节点上的电压即等于电压源的电压值，因此不必再在该节点上使用KCL关系建立方程，而其它节点上的KCL方程中可以将该节点电压作为常量处理。
  2. 电压源V_add加在非地节点a和非地节点b之间，则该两个节点之间的电压保持一个恒定差值，而节点a和节点b上的两个KCL方程均还需要引入一个新的未知量，即流过该电压源的电流值I_v_add（假设正方向为从a到b）。这样增加了一个新的未知量，也增加了va和vb之间有恒定差值这一新的约束方程，再求解新的方程组即可得到所有节点的电压和I_v_add的值。

以上情形2.为一般情况，即每增加一个电压源，会增加一个新的电流变量和一个新的电压约束方程，也等价于在电路规模上多了一个虚拟的特殊“节点“；这就是改进节点法(MNA)的基本思路。

4∗v1+(−1)∗v2+(−2)∗v3+I_v_add(−1)∗v1+2∗v2+(−1)∗v3+0∗I_v_add(−2)∗v1+(−1)∗v2+3∗v3+(-I_v_add)v1+0∗v2+(−1)∗v3+0∗I_v_add​=1=0=1=0.2​(Equ. 2-3)

如果将例题mna_exm1中的NA方程(2-2)的矩阵形式抽象泛化写成：

(G​)∗(Vnode​​)=(Isrc_current​​)(Equ. 2-4)

则在此基础上拓展，例题mna_exm2中MNA方程(2-3)对应的泛化矩阵形式成为：

(GC​BD​)∗(Vnode​Ivoltage_src​​)=(Isrc_current​Vsrc_voltage​​)(Equ. 2-5)

以上式中各项，

  • G：节点电导矩阵（即在电压差下各电阻上产生电流的难易程度，也可包含受控源的系数等；电导为电阻的倒数）。
  • B,C,D：和电压源相关的耦合矩阵。当电路不包含受控源时，矩阵C是矩阵B的转置(即C= BT)，矩阵D为0矩阵。
  • Vnode​：待求节点电压向量；Ivoltage_src​：流过电压源的待求电流向量；右侧已知量Isrc_current​, Vsrc_voltage​分别是电路中各个供电电流源的电流值、供电电压源的电压值所排列而成的电源向量。

方程(2-5)的形式对于多个电压源的情况是适用的，这也是使用MNA方法分析一般线性电路的计算依据。

代码2-2

Python的基本文件操作如打开、读写、关闭和其它脚本语言中也是类似的，都会借鉴C语言中fopen( ), fread( ), fwrite( ), fclose( )等流式I/O相关操作以及对应的Linux低层I/O系统调用。如果第87行按此传统一脉相承，可以直接写为：

netlist = open(netlistFile)

右侧netlistFile是前已赋值的网表文件路径，左侧netlist是open( )函数返回的文件句柄对象，作用类似C语言中常见的“FILE *“类型的文件指针对象。由于文件I/O的情况比较复杂，如较容易发生文件名称有误、文件读写异常等，程序从open( )未必能顺利走到后续配对的close( )，C语言程序中往往需要为此增加不少应对异常的额外代码；因此，在Python打开文件操作时会优先采用目前87行的“with open(…) as…”，来替代直接open( )返回文件对象。采用这样写法后，在程序退出本级with模块后能保证清理资源对象，不需要再手工安排close( )。with是Python的一个关键字，用于按上下文管理员协议对外部资源（例如需要占用/释放配对出现的文件、数据库、网络连接等）自动管理；已支持此协议的open( )函数，其返回的文件对象在离开with语句块时能通过内建的__exit__( )函数自动调用close( )，这样从机制上能避免一直占用资源的漏洞，代码也更加简洁、统一。

wl = line.upper().strip().split()

从网表文件中每次读得符合基本格式的一行元件描述，代码第98行都对应生成一个代表该元件的Component类的实例，并用append( )添加它到列表变量circuit中。Component类的全部定义见代码(2-3)。类中定义了2个方法：__init__( )和matrixFill( )；并定义了类的4个实例变量self.name, self.pNode, self.nNode, self.value。实例变量是该类的每个实例都独立拥有的内存变量；与之形成对比的，类属性则是一个类仅一份的内存变量，所有实例可以共享它。有时候更广泛地，也会将一个类仅一份的数据和方法都称为类属性。本章中还没有定义类属性。

__init__( )是所有的类用于初始化对象的特殊方法(initializer之意)，本身返回值为None；当创建一个类的实例时，自动调用该方法。假设从4个词创建一个新的元件类实例如下：

new_comp = Component(wl[0], wl[1], wl[2], wl[3])

此时即会自动调用__init__(new_comp, wl[0], wl[1], wl[2], wl[3])。创建的新元件实例，必须是__init__( )的第一个参数。根据其它4个参数值，该方法能将新实例内部的4个实例变量初始值设置妥当。

matrixFill( )是类Component的另一个方法。在2.2节中已明确，采用NA或MNA方法求解线性电路，在确定电路的节点名称、节点数目后，需要按电路结构建立起相应的矩阵形式的方程组(2-4)或(2-5)。一个有效的元件目前其类型为R, V, I三者之一，放置在两个确定的节点之间，现将该元件先断开、再将该元件连接复原，请问方程组(2-4)或(2-5)在此过程中如何变化？可以选一个电阻试验各断、连一次，比较方程组的差异。如电路采用MNA求解，对应方程组(2-5)形式，则(2-5)中各个矩阵G,B,C,D以及向量Isrc_current​, Vsrc_voltage​（向量也即某一维度受限的特殊2维矩阵）都可能随元件的连断发生变化。各矩阵两次变化的具体差值，就是连接上该元件后，该元件对于各矩阵所增加的“贡献“。而将一个元件实例的贡献对应添加到所有相关的矩阵中的工作，就由元件类的方法matrixFill( )来帮助实现。

matrixFill( )的大致流程应该为：取得本元件的物理量数值；根据元件连接的两个节点号，到字典变量nodeDict中查找这两个节点的排序位置（即对应矩阵中具体哪一行哪一列）；根据元件是R, V, I中的哪一种，决定添加贡献值到哪些矩阵：

  • 例如元件是电阻，名称以R开头，则在G矩阵两个节点序号对应的两个主对角线位置上添加电阻的导纳（称为自导纳），在两个节点序号对应行、列交叉的位置，减去电阻的导纳（称为互导纳）。
  • 又如元件是电流源，名称以I开头，则在方程右侧供电电源向量中增加其电流值。
  • 再如元件是电压源，名称以V开头，方程右侧供电电源向量中需要对应增加其电压值；另外左侧两个节点电压之间也要增加一个恒定电压差的约束，并且还要考虑此电压源上进出的电流对两个节点电流方程的贡献，即方程组(2-5)中的矩阵B和C都要增加对应的+1, -1元素。

按照2.2节中解释方程组(2-5)各矩阵时所述，当电路不包含受控源时，矩阵C是矩阵B的转置，因此matrixFill( )中目前暂仅相应修改矩阵B，而由主体程序去决定何时将B转置生成C。今后如需要升级程序支持受控源的话，matrixFill( )中也还需要增加参数读入矩阵C和D，并对两者进行具体的填充操作。

在matrixFill( )中多次判断一个节点是否为“地“。地节点在仿真中按电压为0的特殊参考节点考虑，G矩阵中没有任何行列与之对应；因此在增添元件贡献时，当发现有连接节点是地的话，就不需要按一般流程操作（而且也找不到对应的矩阵操作位置）。函数isGround( )根据一个节点的名称回答其是否为“地“。函数返回一个布尔值或True或False，取决于Python关键字“in“的计算结果；in用来检查一个值(这里是nodeName)是否存在于一个可迭代对象(iterable)包含的一系列值中，这里问nodeName是否存在于元组(‘0’, ‘GND’)的两个元素值中，是则为真，见代码如下。

    13	def isGround(nodeName):
    14	    """Return True if 'nodeName' is an alias of Ground."""
    15	    return nodeName in ('0', 'GND')

在给节点和电压源编号以后，代码(2-6)展示了建立和求解NA或MNA方程的主要过程。N是除地以外所有节点的个数，也就是矩阵G的行、列数；M是电压源的个数，等于矩阵B的列数和矩阵C的行数，也是右侧向量Vsrc_voltage​的向量长度。调用NumPy的矩阵生成函数zeros( )可以创建元素均被填充为0的矩阵， zeros( )接受一个元组定义的矩阵形状，如创建的矩阵B.shape值等于(N, M)，即为N行M列。

Result = np.dot(np.linalg.inv(G), vectorIsrc)

其中np.linalg.inv( )为NumPy库中线性代数(Linear Algebra)模块中的求逆(inverse)矩阵函数；np.dot( )为矩阵的点积函数。可以按程序中的分解步骤先求逆再点积，也可以尝试使用直接求解G∗Vnode​=Isrc_current​如下：

Result = np.linalg.solve(G, vectorIsrc)

对于使用MNA方法的情形，则要将矩阵G,B,C,D拼装构成一个新的矩阵A，并在方程右侧垂直堆叠形成新的右侧项。可以看到程序使用了NumPy的两个矩阵堆叠函数hstack( )和vstack( )，先分别水平(horizontally)堆叠矩阵G和B、矩阵C和D，再将两者的结果垂直(vertically)堆叠，构成矩阵A：
