第三章 求解非线性电路

3.1 程序主体

程序脚本文件名称：iccad_newton.py

程序说明：本程序演示对非线性电路的仿真求解。非线性电路方程的基本求解方法为牛顿迭代法（或更精确地称为牛顿-拉夫逊法，Newton-Raphson Method）。算法以迭代方式不断猜测电路各节点的工作电压：根据起始猜测的电压条件将原非线性关系等效为某些线性关系，求解此时对应的线性方程得到新的电压值，再将该值作为继续下一次猜测的起始值；如此循环直到猜测值和计算值之差趋向于零。本程序仅支持固定型号的二极管一种非线性器件，而等效线性电路的求解则依靠第二章的线性电路仿真程序完成，这样代码实现更多聚焦到算法原理和流程上。
程序另演示了Python中面向对象编程(OOP, Object Oriented Programming)基本要素。

程序执行：

本程序的执行和第二章中线性电路仿真器的执行类似，需要在程序执行前准备好电路网表文件。应进入下一级子目录./test_circuits，找到以“diode“开头、后缀名为“.spice“的文件，如执行Linux shell命令ls -l diode*.spice，并使用命令cat显示这些文件的内容，也可以在此子目录内用vi编写新的包含非线性元件的电路网表。

回到iccad_newton.py所在目录，在Linux shell命令行如下键入执行：

$> python3 iccad_newton.py

程序会提问，需要仿真分析哪个电路描述文件？可键入相应文件的路径全名。也可以在命令行直接指定仿真对象文件，如：

$> python3 iccad_newton.py ./test_circuits/diode_exm1.spice

或在交互式环境如ipython3中等效执行命令：

In [1]: run iccad_newton.py ./test_circuits/diode_exm1.spice

程序运行中将不断输出迭代求解中每一轮循环所猜测的二极管上电压降Vd。最后观察到当两轮循环之间Vd的变化已经不大时，程序报告“收敛“(converged)并停止。 运行结果：

3.2 问题需求和算法背景

经过程序运行并观察两个示例电路的网表结构、运行结果后，可以对程序要解决的问题做一归纳：
已知电路在最基本的线性电阻、直流电流源、直流电压源之外，还允许包含一种非线性的二极管器件；该电路以SPICE格式网表表示。需要：

  1. 求解电路各个节点的直流电压值，并输出。
  2. 如果电路包含直流电压源，求解流过该电压源的直流电流值，并输出。

3.2.1 单节点非线性电路求解

如果电路中不包含非线性器件，则所提问题已在第二章中解决。而在电路中出现非线性器件后，物理量守恒定律KCL和KVL依然有效，改进节点分析法(MNA)中处理电压源、受控源的方法也不受非线性器件的影响。对例题diode_exm1这一最简单的非线性电路按照KCL建立方程组；该电路仅一个节点，节点1的电压即为未知量x。电路中电阻的电压-电流关系满足欧姆定律；二极管的电压-电流关系，也就是本程序使用的示例二极管模型的表达式为： Id​=Is​∗(exp(Vd​/VT​)−1)=Fid​(Vd​)(Equ. 3-1) 式中Is​为二极管饱和电流(saturation current)、VT​为二极管热电压(thermal voltage)，两者都是决定不同型号二极管有不同电性能的主要模型参数，两者取值都受到温度影响，但在本程序中均简化为固定值，分别为10fA和26mV。式中Vd​是二极管的正向偏置电压，可以验算当二极管偏置电压Vd​为0时，Id​也为0；在diode_exm1电路结构中Vd​即为待求的未知量x。二极管p-n结反向偏置时电流产生的物理机制和正向偏置不同，但本程序中仍使用了方程(3-1)计算反向偏置电流以简化示例模型，因此在仿真中反向偏置的二极管和实际情况会有一些差异，可稍加注意。函数Fid​(Vd​)是对方程(3-1)中二极管Id​-Vd​函数关系的简化记法。

先假设电路中所有非线性元件上流过的电流都为0，根据KCL列方程，左侧为流出各节点的电流，方程右侧为流入各节点的电流。可列出节点1的电流方程如下： rx​=i(Equ. 3-2)

电路其实退化成了我们熟悉的线性电路，此时即使电路的节点数很多，求解也已没有问题。再考虑在电路中增加非线性元件的影响，针对节点1可列出方程如下： Fid​(x)+rx​=i(Equ. 3-3a)

如定义包含了非线性的电流函数Fnonlinear​(x)=Fid​(x)+rx​−i，则电路diode_exm1的求解问题成为求解非线性方程（组）的一般形式： Fnonlinear​(x)=0(Equ. 3-3b)

艾萨克·牛顿较早使用了多次迭代的方法求解多项式方程并将方法写入书籍，但当时微分、积分本身也还不成熟，书籍正式发表也要在此后的60多年。后来英格兰数学家约瑟夫·拉夫逊使用了微分思想来表述更一般的非线性方程的求解思路，发表了自己的类似成果，时间要早于牛顿书籍的发表近50年。这就是牛顿-拉夫逊法的来历，后续我们简称其为NR方法。

图3-6 牛顿-拉夫逊法(NR方法)示意图

根据NR方法求解方程(3-3b)，在初始猜测x的解为x0​后，等价于图示NR方法的原理，依据下式可计算得到新一轮的猜测解x1​： Fnonlinear′​(x0​)∗(x1​−x0​)=−Fnonlinear​(x0​)(Equ. 3-4a)

将本电路Fnonlinear​(x)的函数定义具体代入上式后也即： [Fid′​(x0​)+r1​]∗(x1​−x0​)=−Fid​(x0​)−rx0​​+i⇒Fid′​(x0​)∗x1​+rx1​​−Fid′​(x0​)∗x0​=−Fid​(x0​)+i⇒Fid′​(x0​)∗x1​+rx1​​=−Fid​(x0​)+Fid′​(x0​)∗x0​+i​(Equ. 3-4b)

  • 将方程(3-4b)和方程(3-3a)进行逐项比较发现：
    方程(3-3a)是非线性方程，无法直接求解x；
    方程(3-4b)是线性方程，x0​是已知量，可以直接求解x1​。

  • 再将方程(3-4b)和方程(3-2)进行逐项比较发现：
    两者都是线性方程可以直接求解，而且方程(3-4b)左侧和右侧都保留有方程(3-2)原有的线性电路关系，即方程(3-2)的线性元件r, i均仍发挥原有作用。

  • 方程(3-4b)对方程(3-2)的具体改变是：
    节点1上对地新增了一项导纳项Fid′​(x0​)，流入节点1的电流新增了一项Fid′​(x0​)∗x0​−Fid​(x0​)。也就是说，在从初始猜测值x0​出发计算下一猜测值x1​时，可以先将电路中的二极管等效为依赖于x0​的一个电阻器和一个电流源，然后直接求解线性方程得到x1​。

以上在求解x1​时依赖于上一轮迭代值x0​的，用于线性化二极管的等效电阻器和等效电流源，称为在这一轮迭代时二极管的“伴随模型“(Companion Model)。可以看到伴随模型的推导出发点是NR方法。由于NR方法使用求导数寻找到x0​处的切线方向，而用一个电阻器加一个电流源正好可以模仿该切线的I-V关系，这样就将问题线性化，使得基于已知x0​计算未知x1​的过程脱离了原非线性函数关系的约束。迭代开始后，每一轮迭代的伴随模型建立和第一轮也是类似的。

3.2.2 多节点非线性电路求解

继续来看多个节点情况下的非线性电路求解，以diode_exm2为例。将例题diode_exm2的电路按照KCL建立方程组，以三个节点电压v1, v2, v3作为未知量。参照对比纯线性方程组(2-1)，为电路diode_exm2建立3个节点上KCL的方程组如下： −Fid​(v3​−v1​)+rg​v1​−0​+rx​v1​−v2​​+rz​v1​−v3​​rx​v2​−v1​​+∞v2​−0​+ry​v2​−v3​​Fid​(v3​−v1​)+rz​v3​−v1​​+ry​v3​−v2​​+∞v3​−0​​=ix​=0=iz​​(Equ. 3-5)

代入具体的电阻、电流值，经整理后得到三元非线性方程组如下： ​−Fid​(v3​−v1​)0Fid​(v3​−v1​)​​+​4−1−2​−12−1​−2−13​​​v1​v2​v3​​​=​103​​(Equ. 3-6)

对比方程组(2-2)，非线性器件带来的主要困难是，在根据KCL构造MNA方程组时，方程组不能再表达为A∗x=b型的线性方程组；然而(3-6)这样形式的方程组正是直接使用NR方法可以求解的，此困难完全可以克服，在课后的练习题中将进行相关实践。但在实际中为了更有规则、更方便地解决问题，会优先使用从NR法派生的“伴随模型“方法。

在多节点、多非线性器件条件下使用“伴随模型“方法，也就是要将从方程(3-2)到方程(3-4b)的诸多方程从一维情况推广到多维。简单地说，先可以将非线性方程组写成两部分矩阵之和的形式，形似方程组(3-6)： FNLdevice​(x)+Glinear​∗x=Ivec​(Equ. 3-7)

这里FNLdevice​()是表达非线性元件电流的函数，在电路具有N个节点时，FNLdevice​()和x均为N维向量形式，Glinear​为NxN矩阵。仿照从方程(3-3b)依据NR方法变化到方程(3-4a)的过程： [FNLdevice′​(x0​)+Glinear​]∗(x1​−x0​)⇒[FNLdevice′​(x0​)​+Glinear​]∗x1​​=−FNLdevice​(x0​)−Glinear​∗x0​+Ivec​=−FNLdevice​(x0​)+FNLdevice′​(x0​)∗x0​​+Ivec​​(Equ. 3-8)


对比方程(3-7)和(3-8)，即可看到(3-8)中新增代表伴随模型电阻器的FNLdevice′​(x0​)项和代表伴随模型电流源的[−FNLdevice​(x0​)+FNLdevice′​(x0​)∗x0​]项，而(3-7)中代表所有非线性元件电流关系的FNLdevice​(x)不再施加到未知量x1​上。

当函数FNLdevice​()和其自变量x均为N维向量时，导数FNLdevice′​(x)需要表达原函数FNLdevice​()的N个分量中各个分量因自变量x的N个分量中各个分量的微小变化而变化的程度，这是一种N对N的“多对多“关系，由雅可比矩阵(Jacobian Matrix)表示，形式上为NxN矩阵，其一般定义为：

x=​x1​x2​⋮xN​​​,f(x)=​f1​(x)f2​(x)⋮fN​(x)​​⇒f′(x)=Jf​(x)=​∂x1​∂f1​​∂x1​∂f2​​⋮∂x1​∂fN​​​∂x2​∂f1​​∂x2​∂f2​​⋮∂x2​∂fN​​​⋯⋯⋱⋯​∂xN​∂f1​​∂xN​∂f2​​⋮∂xN​∂fN​​​​​

举例如当N=2， f(x,y)=(f1​(x,y)f2​(x,y)​)=(x2ysin(x+3y)​)⇒Jf​(x,y)=(2xycos(x+3y)​ x2 3cos(x+3y)​)


回到方程(3-8)，将雅可比矩阵形式的FNLdevice′​(x)简记成JFNL​(x)，注意它和Glinear​都是NxN矩阵，得到下式：

[JFNL​(x0​)+Glinear​]∗x1​=[−FNLdevice​(x0​)+JFNL​(x0​)∗x0​]+Ivec​(Equ. 3-9a)


而如果此时去除原电路中所有非线性元件，而仅考虑其线性部分，方程式应为：

Glinear​∗x1​=Ivec​(Equ. 3-9b)

比较方程(3-9a)和方程(3-9b)后可以看到非线性电路在迭代中产生的作用，等效于在方程左侧矩阵中增减部分导纳量，在方程右侧电流向量中增减部分电流值。

这里应注意到，方程(3-9a)左侧JFNL​(x)矩阵中应该有大量零元素，但非零元素存在的条件为：某一非线性元件对所连接的某一个节点吞吐的电流值，可能受到哪些节点电压的影响。如对于一个三端口非线性元件，其每个端口吞吐的电流，都会受到自身3个端口节点电压的影响，这样JFNL​(x)矩阵中最多新增3*3=9项非零元素。

再以三端口非线性元件的3个端口节点为例看方程右侧。方程(3-9a)提示按电路中所有N个节点上的猜测电压向量值x0​，逐个分量计算它们对3个端口节点的电流贡献，贡献求和后形成对3个端口节点的伴随电流值，增加到方程(3-9b)右侧项的原有线性电流源Ivec​上。

本章程序执行实例求解中最后一次迭代的等效电路，在迭代收敛后保存在电路网表文件newton.iter.1.spice中；计算该电路流过每一对伴随电阻器和伴随电流源的电流之和，对照此电阻器两端的电压差，应都正好可以满足方程(3-1)中二极管的非线性Id​-Vd​函数关系。


再回到原始的问题，来看一看迭代求解的操作过程。

  1. 已知电路可以一般表达为非线性方程组，其形式如方程(3-3b)。
  2. 由于电路本身由线性元件和非线性元件构成，可以将其转化为方程(3-7)形式。
  3. 初始猜测方程的解值为x0​，按照方程(3-9a)计算得到迭代解x1​。计算过程中使用非线性元件的NR伴随模型，重点为方程左侧导纳矩阵新增一批非零项、右侧各节点上增加各个非线性元件对应的伴随电流源的流入贡献。
  4. 如果此时检验Fnonlinear​(x1​)离0尚远，或与之等价的，x1​和x0​之差的绝对值尚不可忽略，则将x1​赋值给x0​，继续回到步骤3进行下一轮的猜测。

如展开上述步骤3和4之间的循环，则可以看到以下计算序列：

[JFNL​(x0​)+Glinear​]∗x1​=[−FNLdevice​(x0​)+JFNL​(x0​)∗x0​]+Ivec​[JFNL​(x1​)+Glinear​]∗x2​=[−FNLdevice​(x1​)+JFNL​(x1​)∗x1​]+Ivec​[JFNL​(x2​)+Glinear​]∗x3​=[−FNLdevice​(x2​)+JFNL​(x2​)∗x2​]+Ivec​[JFNL​(x3​)+Glinear​]∗x4​=[−FNLdevice​(x3​)+JFNL​(x3​)∗x3​]+Ivec​………(Equ. 3-10)


按此序列不断迭代到Fnonlinear​(xn+1​)约等于0，或与之等价的，xn+1​和xn​之间距离很近，称为迭代过程“收敛“时，停止循环过程。

在本章中的非线性元件仅限于某一种二极管，因此描述元件本身特性的函数FNLdevice​()和FNLdevice′​()也是相当清晰的。当1947-1948年威廉·肖克利和同事们发明最初的双极型晶体管后，他研究了p-n结并提出了二极管I-V关系的指数模型，称为肖克利二极管方程，描述经过二极管的电流Id​和二极管上的电压Vd​的关系为： Id​=Is​(enVT​Vd​​−1) 或写成表达式， Id​=Is​∗(exp(Vd​/(n∗VT​))−1)(Equ. 3-11a) Id​对Vd​的导数为： Id′​=Is​∗exp(Vd​/(n∗VT​))/(n∗VT​)(Equ. 3-11b) 以上两式中Is​为二极管的饱和电流。n为理想度因子，在本章中取值为1，对实际二极管可以根据其电流表现稍加调整。VT​为二极管热电压，在室温时约为26 mV，其反映了温度对载流子动能的影响，计算依据为k∗T/q；这里k为玻尔兹曼常数、T为绝对温度、q为电子电荷。肖克利二极管方程的提出，也开启了集成电路仿真的后续发展道路。

如再从例题diode_exm2对应的方程(3-6)进一步展示具体的NR伴随模型求解方法，且取二极管模型中理想度因子n为1，则此时各相关函数具体化为： Fid​(v)=Is​∗(exp(v/VT​)−1);Fid′​(v)=Is​∗exp(v/VT​)/VT​ V=​v1​v2​v3​​​;FNLdevice​(V)=​−Fid​(v3​−v1​)0Fid​(v3​−v1​)​​ FNLdevice′​(V)=JFNL​(V)=​Fid′​(v3​−v1​)0−Fid′​(v3​−v1​)​ 0 0 0​ −Fid′​(v3​−v1​) 0 Fid′​(v3​−v1​)​​

电路中三个节点电压的迭代初值分别为v10​​，v20​​，v30​​；下一步迭代求解的节点电压值为v11​​，v21​​，v31​​；根据方程(3-9a)可以将方程(3-6)的迭代序列具体化为：

    22	    return Is_dmodel * (math.exp(V_d / Vt_dmodel) - 1)

    25	    return Is_dmodel / Vt_dmodel * math.exp(V_d / Vt_dmodel)

    28	    return 1.0 / G_eq(V_d)

    31	    return I_d(V_d) - G_eq(V_d) * V_d

   141	            self.equ_diode_lines.append("Iequ_%s %s %s %e"
   142	                                        % (dname, dnode1, dnode2, I_eq(vd)))
   143	
   144	    def judgeConverged(self):
   145	        for node in self.node_volt_iter0.keys():
   146	            if abs(self.node_volt_iter0[node]
   147	                    - self.node_volt_iter1[node]) > self.volt_tolerance:
   148	                return False
   149	        return True

现在假想有一种理想化的三端场效应器件，其名称为YFET，对应在SPICE网表中的元件名称假想以字母Y开头，顺序排列三端的名字分别为源极(S)、栅极(G)、漏极(D)。其I-V关系如下：

技术知识拓展问题：

使用NR方法进行电路仿真，最大的问题是如何快速收敛。对于大型电路仿真，基于SPICE的电路仿真器会组合使用各种收敛方法，但是由于电路本身的情况差异很大，某种收敛策略也未必能保证成功；其基本思路一是希望借用一系列容易收敛的仿真问题来猜测尽量接近准确解的迭代初值；二是对猜测值明显不合理的情况，例如p-n结两端节点的电压差高达数伏，进行适当纠正或限制。
